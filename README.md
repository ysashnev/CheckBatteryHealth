# Check Battery Health

Застосунок для macOS, що живе в рядку меню і через Bluetooth читає стан
LiFePO4-акумуляторів з їхніх BMS. Можна підключити кілька акумуляторів одночасно.

**У рядку меню:**

- іконка-акумулятор, заповнена за найнижчим зарядом серед підключених батарей,
  зі значком режиму: ⚡ — заряджається, ↓ — розряджається;
- відсоток заряду кожного акумулятора (`84% · 82%`);
- за бажанням — скільки часу залишилось і потужність заряду/розряду
  (`84% 2 год 15 хв 96 Вт`);
- при низькому заряді іконка стає червоною.

**У вікні** — картка для кожного акумулятора (клік по назві згортає/розгортає):

- рівень заряду, режим і **скільки часу залишилось** до розряду при поточному
  споживанні (або до повного заряду);
- залишок ємності (А·год) і енергії (Вт·год);
- напруга, струм, потужність, температура, цикли, стан MOSFET;
- напруги комірок і розбаланс (Δ мВ);
- попередження захисту BMS (перенапруга, перегрів, КЗ тощо).

**Також:**

- системне сповіщення про низький заряд (поріг 10/20/30/50% або вимкнено);
- запам'ятовує акумулятори і сам перепідключається при втраті зв'язку;
- запускається при вході в систему (вмикається при першому запуску,
  вимикається в ⚙️).

## Підтримувані BMS

| BMS | BLE-сервіс | Що читається |
|---|---|---|
| JBD / Xiaoxiang (Overkill Solar, багато китайських LiFePO4) | `FF00` | усе |
| Daly Smart BMS (протокол `A5`) | `FFF0` | усе |
| Стандартний BLE Battery Service | `180F` | лише % |

Якщо ваш акумулятор не розпізнався, застосунок покаже список його BLE-сервісів —
надішліть його (і модель батареї/BMS), щоб додати протокол. Нові протоколи
додаються одним файлом у `Sources/CheckBatteryHealth/Protocols/`
(реалізація `BMSProtocol` + запис у `BMSRegistry`).

> Важливо: BMS зазвичай підтримує лише одне BLE-з'єднання. Закрийте фірмовий
> застосунок на телефоні, інакше Mac не зможе підключитися.

## Встановлення

Потрібна macOS 13 Ventura або новіша.

### Готова збірка

Завантажте `CheckBatteryHealth.zip` з артефактів останнього запуску
GitHub Actions (вкладка **Actions → Build macOS app**), розпакуйте і перенесіть
у «Програми». Оскільки збірка не нотаризована, при першому запуску:
правий клік → **Відкрити** → **Відкрити**.

### Збірка з коду

Потрібні Xcode або Command Line Tools (`xcode-select --install`). Якщо є лише
Command Line Tools з SDK macOS 27, скрипт сам вибере сумісний старіший SDK.

```bash
./scripts/build_app.sh             # створює build/CheckBatteryHealth.app
INSTALL=1 ./scripts/build_app.sh   # + копіює в /Applications
open build/CheckBatteryHealth.app
```

При першому запуску macOS попросить дозволи на Bluetooth і сповіщення — дозвольте.

#### Постійний підпис (щоб дозвіл на Bluetooth не скидався)

Без сертифіката скрипт підписує застосунок ad-hoc, і після кожної збірки macOS
вважає його новим застосунком — дозвіл на Bluetooth доводиться давати знову.
Якщо в Keychain є сертифікат для підпису коду з назвою
**CheckBatteryHealth Local Signing** (можна самопідписаний), скрипт підписує ним,
і дозвіл зберігається між збірками. Іншу назву сертифіката можна передати через
`SIGN_IDENTITY="..."`.

## Використання

1. Натисніть на іконку акумулятора в рядку меню — пошук BMS поруч почнеться сам.
2. Відкрийте список **Вибрати акумулятор ▾** і виберіть свій — далі все працює
   автоматично.
3. Щоб додати ще один — **Додати акумулятор ▾** у тому ж місці.

У меню ⋯ на картці — підключення, від'єднання і «Забути пристрій».
У ⚙️ — інтервал оновлення, показ часу і потужності в рядку меню, поріг
попередження про низький заряд і автозапуск.

## Як рахується залишок часу

`час = залишок ємності (А·год) / струм розряду (А)` — тобто при поточному
навантаженні. Для заряду: `(номінальна ємність − залишок) / струм заряду`.
Струм менше 0,05 А вважається станом спокою.
