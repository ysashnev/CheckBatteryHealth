# Check Battery Health

Застосунок для macOS, що живе в треї (рядку меню) і через Bluetooth читає стан
LiFePO4-акумулятора з його BMS:

- рівень заряду (%) — прямо в рядку меню;
- **скільки часу залишилось** до розряду при поточному споживанні
  (або до повного заряду, якщо батарея заряджається);
- залишок ємності (А·год) і енергії (Вт·год);
- напруга, струм, потужність, температура, цикли, стан MOSFET;
- напруги комірок і розбаланс (Δ мВ);
- попередження захисту BMS (перенапруга, перегрів, КЗ тощо).

Застосунок запам'ятовує вибраний акумулятор, сам перепідключається при втраті
зв'язку і може запускатися при вході в систему.

## Підтримувані BMS

| BMS | BLE-сервіс | Що читається |
|---|---|---|
| JBD / Xiaoxiang (Overkill Solar, багато китайських LiFePO4) | `FF00` | усе |
| Daly Smart BMS (протокол `A5`) | `FFF0` | усе |
| Стандартний BLE Battery Service | `180F` | лише % |

Якщо ваш акумулятор не розпізнався, застосунок покаже список його BLE-сервісів —
надішліть його (і модель батареї/BMS), щоб додати протокол. Нові протоколи
додаються одним файлом у `Sources/CheckBatteryHealth/Protocols/`
(реалізація `BMSProtocol` + запис у `BMSRegistry`).

> Важливо: BMS зазвичай підтримує лише одне BLE-з'єднання. Закрийте фірмовий
> застосунок на телефоні, інакше Mac не зможе підключитися.

## Встановлення

Потрібна macOS 13 Ventura або новіша.

### Готова збірка

Завантажте `CheckBatteryHealth.zip` з артефактів останнього запуску
GitHub Actions (вкладка **Actions → Build macOS app**), розпакуйте і перенесіть
у «Програми». Оскільки збірка не нотаризована, при першому запуску:
правий клік → **Відкрити** → **Відкрити**.

### Збірка з коду

Потрібні Xcode або Command Line Tools (`xcode-select --install`).

```bash
./scripts/build_app.sh             # створює build/CheckBatteryHealth.app
INSTALL=1 ./scripts/build_app.sh   # + копіює в /Applications
open build/CheckBatteryHealth.app
```

При першому запуску macOS попросить дозвіл на Bluetooth — дозвольте.

## Використання

1. Натисніть на іконку батареї в рядку меню.
2. Натисніть **Шукати** — акумулятори з відомим BMS будуть угорі списку.
3. Виберіть свій — далі все працює автоматично.

Через ⚙️ можна змінити інтервал оновлення, увімкнути автозапуск, вибрати
інший пристрій або забути поточний.

## Як рахується залишок часу

`час = залишок ємності (А·год) / струм розряду (А)` — тобто при поточному
навантаженні. Для заряду: `(номінальна ємність − залишок) / струм заряду`.
Струм менше 0,05 А вважається станом спокою.
